# Text ingestion implementation plan

Use the approved user scope and default autonomous parallel execution. Coordinator owns shared contracts, package scripts, docs, integration and final external actions. No VM deployment or live model call needed.

1. **Core metadata lane**: extend optional `StructMetadata.publisher`, strict codec allowlists/parser, EPUB OPF date/publisher emission. Tests first for escaped publisher and dates and codec roundtrip. Own only relevant src files + new focused core tests. Verify typecheck/focused tests, publish interface.
2. **Adapter lane**: `adapters/text/ingest.mjs` exports `ingestText`, `inspectText`, `validateCleanupPlan`; source bound to strict UTF-8 bytes, exact nonblank line units with `line-N` IDs and offsets, keep/remove/review ledger, valid sealed 0.2.0 document and conservation counts. Metadata and source-neutral diagnostics; report raw source and whitespace accounting. Own module and `tests/text-ingestion.test.mjs`. Test first all specified contracts and receipt/render integration against dist public modules.
3. **Judgment lane**: `adapters/text/judge.mjs` exports `judgeText(sourceBytes, {engine, model?, timeoutMs?, executable?})`; inspection derived internally from sourceBytes using `inspectText`: schemaVersion 1.0.0, sourceSha256, blocks [{id,text,start,end,line}]. Output strict cleanup plan with complete ID coverage, actor matches engine and prompt hash. Own transport + `tests/text-judge.test.mjs`, no ingestion/CLI edits. Read local CLI help/official docs; use argv spawning, temporary cwd, hard bounds, abort/timeout kill process group and bounded result reads. Tests fake executables, never call models.
4. **Examples lane**: `adapters/text/examples/` metadata + derived cleanup plans for supplied two articles, raw inputs in ignored `private/`; `adapters/text/check-examples.mjs` regression script; `tests/text-examples.test.mjs` synthetic/manifest validations. Await contract settled before implementation. Preserve source hashes and expected content counts, no raw prose committed. Test old line masks precisely and no silent correction. Copy originals for local verification only.
5. **Coordinator CLI/docs**: `adapters/text/artifacts.mjs` owns exclusive non-destructive publication and tests/text-output.test.mjs race regressions; `adapters/text/text2epub.mjs` parse flags, source/metadata/plan bounded reads, call inspect/ingest/judge, seal/render public paths, hashes and staged artifact output; no shell, no overwrite. Tests first `tests/text-cli.test.mjs`. Add scripts (`text:epub`, `text:examples`), README/adapter README and reference-adapter ADR. Run build before dist-consuming adapter tests. Document VM CLI usage and local-replay privacy, uncertainty semantics, line-unit segmentation limitation.
6. **Integration**: baseline + focused tests, reproduce both article EPUBs using saved plans, full npm test/build/typecheck/source-boundary/test:package. Commit coherent integrated revision on feat/text-ingestion, fresh read-only review at immutable SHA; assign findings, fix with tests and fresh review affected scope. Complete only when no actionable findings remain.

Review focus: source offsets including CRLF/non-BMP characters; missing model decisions/hostile prose; fake executable descendants/timeouts; publisher escaping through strict codecs; output/source path collisions and pending-review EPUB refusal.
